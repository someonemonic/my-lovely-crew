# My Lovely Crew 💛

ปฏิทินตารางบินลูกเรือ EVA Air สีเหลืองอ่านง่าย — เปิดใช้ได้ที่ **https://someonemonic.github.io/my-lovely-crew/**

## วิธีใช้
1. แคปหน้าจอปฏิทินในแอปของสายการบิน (แบบมือถือ ทั้งหน้า)
2. เปิดเว็บ → กด **อัปโหลดตารางบิน** → เลือกรูป ปฏิทินขึ้นเองในไม่กี่วินาที
   - รูปถูกอ่านในเครื่องที่เปิดเว็บ (Tesseract OCR) ไม่ถูกส่งไปไหน · ครั้งแรกโหลดตัวอ่านราว 7 MB
   - เส้นทาง ธง และเวลา Report (≈) มาจากเที่ยวบินที่เคยบิน ถ้าเป็นเที่ยวใหม่ กดวันนั้นแล้วตั้งเวลาเองได้
3. ถ้ารูปอ่านไม่ออกหรืออ่านผิด: กด **🤖 ให้ AI อ่านรูปนี้แทน / อ่านผิด? ให้ AI อ่านรูปนี้ใหม่** — รูปถูกส่งผ่านตัวกลาง (Cloudflare Worker `my-lovely-crew-ai`) ให้ Claude Haiku อ่าน ค่าใช้จ่ายตัดจากเครดิตใน Claude Console
4. ทางสำรองสุดท้าย: **"หรือให้ Claude ในแชทอ่านให้"** (คัดลอกคำสั่ง → ส่งรูปให้ Claude → วางผล)

- กดวันไหนก็ได้เพื่อดูรายละเอียด แก้เวลา Report หรือตั้งเป็นวันพิเศษ (สี + หมายเหตุ)
- เลือกธีมสีได้ 4 แบบ · กด 📷 บันทึกเป็นรูป เพื่อเซฟลงมือถือ
- ข้อมูลตารางเก็บไว้ในเบราว์เซอร์ของเครื่องที่เปิดเท่านั้น

`ocr/` คือไฟล์ของ [tesseract.js](https://github.com/naptha/tesseract.js) (Apache-2.0) ที่ใช้อ่านรูป
ไฟล์ในนี้เป็นเว็บที่ build แล้ว (`index.html` ไฟล์เดียว) ซอร์สโค้ดเก็บแยกไว้

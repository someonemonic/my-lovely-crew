# My Lovely Crew 💛

ปฏิทินตารางบินลูกเรือ EVA Air สีเหลืองอ่านง่าย — เปิดใช้ได้ที่ **https://someonemonic.github.io/my-lovely-crew/**

## วิธีใช้
1. กด **คัดลอกคำสั่ง** ในเว็บ
2. เปิดแชทกับ Claude ที่ claude.ai → เปิด **Web search** → แนบรูปตารางบิน → วางคำสั่งแล้วส่ง
3. คัดลอกผลลัพธ์ (ก้อน JSON) กลับมาวางในเว็บ แล้วกด **สร้างปฏิทิน**

- เวลา Report ที่มี ≈ เป็นค่าประมาณ (เวลาออก − 1 ชม. สำหรับเที่ยวที่ออกจากกรุงเทพฯ) กดวันนั้นแล้วแก้เป็นเวลาจริงได้
- เลือกธีมสีได้ 4 แบบ · กด 📷 บันทึกเป็นรูป เพื่อเซฟลงมือถือ
- ข้อมูลตารางเก็บไว้ในเบราว์เซอร์ของเครื่องที่เปิดเท่านั้น ไม่ได้ส่งขึ้นเว็บไซต์นี้

ไฟล์ในนี้เป็นเว็บที่ build แล้ว (`index.html` ไฟล์เดียว) ซอร์สโค้ดเก็บแยกไว้
